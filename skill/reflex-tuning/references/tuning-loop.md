# 调优闭环方法（reflex-tuning 参考）

完整实验记录与逐次结论见仓库 `docs/threshold-fitting.md`；本文是目标侧可执行的摘要。

## 1. 为什么需要调优

L1 用本地决策模型（SemIf/Qwen3.5-4B）给每条事实打 `p(yes)`，再用一个阈值决定是否叫醒 L2。
阈值和判据措辞都是人拍的，而**判据质量**与**代价权衡**是两件事：

- 判据决定"分数分不分得开"（改判据是主杠杆）；
- 阈值决定"在哪切"（只有在判据固定后才有意义）。

没有历史数据时，两者都只能凭感觉；shadow + 回放把两者都变成可测的。

## 2. 影子记录（不改变判定）

`shadow-semif.sh` 包在真实打分外面，把每轮**全部条目**（含阈值以下的）落盘：

```json
{"ts":..., "mode":"live", "tag":"x-timeline", "key":"<sha1(tag+question+state)>",
 "state_hash":"<sha1(state)>", "score":0.87, "threshold":0.93, "passed":false,
 "question":"...", "state":"...（截断 1200 字，供标注）"}
```

- `key` 用于同判据去重；`state_hash` 用于**跨判据对齐**（判据 A/B）。
- 记录器与脚本同目录，不依赖运行目录副本；写失败静默（判定不能因记录失败而变）。

## 3. 回放

`shadow_replay.py --target <tag> --script <target.sh> --source <source> --days <dates> --chunk 40`

- 把 facts 按生产批次重放进 target；target 的 SemIf 调用经 wrapper 落 shadow。
- 批次与逐条等价（实测 12 vs 40 条分数完全一致），因此回放分数=线上分数。
- 注意：**回放的分批粒度与线上不同**（线上是每 15 分钟到达的小批），涉及"时间窗口"的策略
  （如单条暂存）不能用回放次数直接和线上比较；用 `wake_policy_sim.py` 按发布时间仿真。

## 4. 标注与拟合

- 分层抽样：边界带 `[0.5,0.96]` 抽 75%、其余 25%，权重 = 1/入选概率。
- 期望效用：`ΔU(τ) = Σ_{s_i ≥ τ} w_i (y_i R − 1)`，`R = (真阳价值 + 漏报代价) / 误报代价`。
  `τ* = argmax ΔU`；bootstrap 给区间。R 只依赖比值，不需要三个代价的绝对值。
- 固定基线：always-wake（精度=正例率）、always-suppress（召回 0）、同量随机（精度=正例率、召回=k/N）。
  没有这三行，"模型比阈值好"可能只是构成差异。
- 风险证书：Clopper-Pearson 单侧界；0 误报时证明误报率 ≤ r 需 `n ≥ ln(α)/ln(1−r)`（α=0.05, r=5% → 59）。
- 校准：Platt/Isotonic + 5 折 CV 的 ECE；校准后唤醒概率阈值 = `1/R`。

## 5. 判据 A/B

两套判据各跑一份回放（tag 不同），按 `state_hash` 对齐，用同一份标签比较 P/R 与拟合阈值。
实测结论（2026-10-18，x-timeline）：

- "不校准的分数 + 手调阈值"：精度 80%、召回 78%（R≈2 口径）；
- 只改判据（v2.1）后同口径 84.6%/91.7%，唤醒量 +12%；
- 再加"开发者相关性"第三条件（v2.2）反而劣化（召回 61%、效用下降）→ 负结果不采用；
- guard 模式（第二问过滤已通过条目）也劣化 → 残余噪音归 L2，不再堆 prompt。

## 6. 唤醒级评估与策略

- 唤醒级标签是自然抽样（每次真实唤醒一条），可对唤醒总体下结论；
- 回放构造唤醒（按发布时间聚类 + OR 语义）用于在 live 样本攒够前看方向；
- 单条目 vs 多条（实测 37% vs 100%）→ `wake_policy.py`：单条暂存等第二条（默认 60 分钟），
  ≥0.98 立即发；策略仿真给出候选参数，上线后持续看"暂存过期丢弃"的条目。

## 7. 上线与回滚

- 判据、阈值默认值都在 target 脚本里 → 改完下一轮生效（热更新）；
- 策略开关：`REFLEX_X_DEFER=0`（x-timeline 示例），其他 target 用各自 env；
- 每次改动都要能回答：标签口径变了吗？阈值重拟合了吗？回滚命令是什么？
